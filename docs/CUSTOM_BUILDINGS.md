# 自訂建築第一版

在圖台最左側功能列按「自訂建築」（位於「資料」下方）。RVT 共用座標核對暫時保留；此功能獨立於 BIM 與周邊 OSM 建物。

## 操作
1. 匯入地籍 GeoJSON 或 ZIP Shapefile，選取宗地；也可按「地圖繪製基地」依序點選頂點後完成，或用「載入示意基地」試操作。
2. 確認占地面積（由範圍自動計算），指定分戶方向、地上／地下層數與層高、每層戶數及單／雙排配置。
3. 按「產生／更新三維建築」。新建築直接沿用所選範圍的輪廓，保留凹角、孔洞與多部份範圍；同層分戶面積加總等於樓板面積。單／雙排依面積比例分割，不保證真實格局。匯入地籍仍須由使用者確認是否代表建築占地；不是法規退縮計算。
4. 在 2D／3D 檢視，選取單一樓層後點選住宅，查看樓層、戶號、穩定 ID、估算面積與示意狀態。地下室整層呈現，採抬升示意方式，非真實地表高程。
5. 可新增多棟、切換編輯與刪除。修改同棟保留建築 ID，住宅 ID 由建築／樓層／戶序組成；改變戶數後幾何會重新分配，ID 不代表原住戶身份。
6. 按「儲存於本機」保存於目前瀏覽器 localStorage；重新載入後按「讀取本機存檔」。亦可匯出／匯入 JSON。未按儲存的修改不會自動保存，清除瀏覽器資料也會清除本機存檔。

## 地籍匯入
- 支援 WGS84 經緯度（EPSG:4326）、TWD97 TM2 121／119 分帶（EPSG:3826／3825）。GeoJSON 無 CRS 定義時依標準視為 WGS84；不依數字自動猜測 TWD97。其他系統須先轉檔。
- ZIP 每次只含一個 Polygon／PolygonZ／PolygonM SHP。自動判讀需同名 PRJ；缺少或不支援時先手動指定已知座標系統。投影單位必須為公尺。
- DBF 保留地號等屬性，CPG 可指定 UTF-8 或 Big5；無 CPG 預設 UTF-8。出現文字亂碼時請先補正 CPG。非多邊形、加密、ZIP64 與分割 ZIP 不支援。
- 輸入上限 20 MB、ZIP 解壓合計 25 MB、100 個 ZIP 項目、1,000 圖徵／100,000 座標。ZIP deflate 需瀏覽器支援 DecompressionStream。CRC 未作獨立驗證，檔案結構與輸出長度會檢查。
- 單一 polygon 上限 2,000 頂點；實際配置的選定宗地總頂點上限 500，超過時先簡化資料，避免本機幾何計算卡住。不自動簡化地籍邊界。
- 面積採本地公尺近似投影計算，介面明示估算；不是法定登記面積或測量成果。保留原始宗地屬性，地籍範圍與建築占地分別管理。

## 第一版範圍
最多 50 棟；每棟地上 1–100 層、地下 0–10 層、每層 1–20 戶；單層高度 2–10 m，每棟產出住宅加地下室最多 2,000 區塊。地上各層使用相同戶數與層高；未提供逐層覆寫、任意建築輪廓編輯、多宗地合併、真實室內格局或正式門牌綁定。住宅點為生成區塊的代表位置，不是入口。

所有解析與量體產生留在瀏覽器本機，沒有新增套件下載、模型上傳或後端資料庫。地圖底圖的原有網路服務仍依圖台設定運作。

## 資料清單整合
建築生成或載入後顯示於「資料」頁，卡片類型為「自訂建築」，提供獨立顯示、檢視與編輯。按「儲存於本機」後回到資料頁；下次開啟圖台會自動還原已儲存建築。尚未儲存的生成／修改不保證跨重新載入保留。

## 2026-10-22：占地輪廓與樓板面積
新模型使用 footprintMode=parcel，保留原多邊形／MultiPolygon 輪廓及孔洞；分戶方向只改變切割方向，不旋轉建築外形。使用既有 Three.js ShapeUtils 分解輪廓後依等面積分戶，合併共用邊，不另扣 0.15m 間隙。顯示單層、地上合計及地下合計樓板面積；未扣公共空間、牆體或其他項目，因此不是住宅實坪或正式登記面積。
舊存檔未指定模式時維持原矩形，避免自動改動；按資料卡編輯並重新產生後，改為新輪廓並可儲存。29 項 Node 測試通過，包含凹形／孔洞／分離區域、單雙排與多種方向、面積守恆；最新 WebGL 外觀尚未自動驗證。

刪除建築會立即同步更新本機存檔，不需再按儲存；重新整理不會還原已刪除的模型。其他棟未儲存的修改仍需自行儲存。已匯出的 JSON 檔保持原內容。
