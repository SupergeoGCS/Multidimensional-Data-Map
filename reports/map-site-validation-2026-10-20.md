# 本機地圖站台驗證

日期：2026-10-20。MapLibre GL JS 5.6.0、Three.js 0.169.0、Python 3.12。介面以 IAB 實際操作驗證。

| 檢查 | 結果 |
|---|---|
| 街道地圖、比例尺與控制項 | 通過，臺灣初始視角可見 |
| 2D／3D 互切 | 通過，俯仰切換；2D 隱藏手動暫放的 BIM |
| STR 獨立三維預覽 | 通過，GLB 可見；線框、重設可操作 |
| 構件點選 | 通過，實際點選回報混凝土矩形梁與 IFCBEAM；不代表完整 BIM 屬性 |
| 手動暫放位置 | 通過，121.25／25.01 僅為本次操作測試座標，未寫入預設或認定是真實基地 |
| GeoJSON 匯入與移除 | 通過，sample.geojson 的兩筆示意圖徵；3D 模式高度以 height 屬性顯示 |
| GLB 本機替換 | 通過，來源／品質欄位改為未知；載入後可開啟獨立預覽 |
| 瀏覽器 console | 已測流程未觀測到 error／warn |
| app.js 語法檢查 | Node --check 通過 |
| unittest | 10 項通過，其中 3 項新增伺服器路徑邊界與目錄清單保護 |
| 實際 HTTP 路由 | 首頁、app.js、Three.js、模型與預覽 200；原始 RVT、.git/config、vendor 目錄清單與編碼路徑穿越均 404 |
| 原生 IFC、精確位置、效能目標 | 未測；仍由前處理與後續正式驗收負責 |

程式庫、模型、字體（系統字體）均不需 runtime CDN。街道圖仍請求 OpenStreetMap；沒有圖磚預抓、模型上傳或雲端部署。使用者匯入與暫放只在分頁記憶體，重新載入會重設。

QA 初次 server 受 sandbox loopback 限制；在外部執行相同 server 且仍只綁定 127.0.0.1 後正常。測試後停止 QA server，使用者雙擊啟動地圖.cmd 可重啟。手機版有資料面板切換按鈕；未進行實機手機、特殊 GLB 壓縮或大型模型壓力測試。
