# 本機 STR IFC 匯出交接

目前 STR 副本已成功開啟。Windows 自動化工具會在聚焦主視窗時收起選單，亦無法可靠操作 IFC 匯出對話框；這一步改由使用者完成。不要關閉或重新升版模型。

1. 在目前 STR 副本選「檔案 → 匯出 → IFC」。
2. 選 IFC4 Reference View 預設；若此安裝沒有該選項，先保留視窗並告知實際可選項，不任意更改模型。
3. 在修改設定核對：連結模型不匯出；不要限制為「僅匯出目前視圖可見元素」（本次先取宿主模型）；座標基準選內部原點。不要猜地圖座標，不自行置中或調整真北。若內部原點選項不存在，記錄實際選項後告知。
4. 使用 IFC 格式（不是 IFCZIP／IFCXML）。保留 IFC 共用屬性集；若可用，啟用基本數量與 Revit 元素 ID。其餘選項保留預設，不為消除警告刪除或取消接合構件。
5. 匯出至已建立的本機資料夾：

`C:\Users\benhs\OneDrive\文件\三維圖台\data\ifc\revit-str-2026-10-21`

建議檔名 `A18A-CO-STR-native.ifc`。若已有同名檔，使用新檔名，不覆寫。

6. 若匯出設定有儲存／匯出設定 JSON 功能，另存至 `reports/revit-export-str-2026-10-21`，便於重現。沒有這功能時，回報實際 schema、座標基準、連結選項及警告即可。
7. 等 Revit 匯出完成後回覆「IFC 已匯出」，若出現錯誤則回報錯誤文字。不必上傳模型到聊天。

取得 IFC 後，由本機固定版本 IfcConvert 接續 GLB，核對日誌、構件、樓層、包圍盒與代表性幾何。這次手動設定的成功尚不等於正式幾何驗收；定位契約仍 pending。
