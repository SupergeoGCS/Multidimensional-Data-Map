# 雙 BIM 資料圖層驗證

- 同一站台新增開源方案／Revit IFC 方案兩張資料卡，各自顯示來源、大小與不同統計單位（構件／幾何節點，不作一對一數量比較）。
- 兩份 GLB 各自快取，單一來源載入失敗可重試且不污染另一來源；三維檢視切換會釋放先前控制器、材質副本、grid 與 renderer，保留來源幾何供地圖重用。
- 地圖以一個 custom layer 下兩個具來源標識的 group 分別切換，並保留整體 BIM 主開關、2D 隱藏與 3D 恢復。
- 暫放採各自置中與底部對齊，UI 明示為視覺對照，不宣稱共同座標套合正確。未修改 GLB 或 IFC。
- Node 語法檢查及 5 項 Node 測試通過（來源隔離／重試、獨立可見性與 master 恢復、既有 3 項底圖切換）。
- 實際 IAB：兩張卡與圖層數 02；分別開啟兩模型皆 loading 隱藏且只有 1 個 viewer canvas；暫放後關閉開源圖層，切換 2D→3D／street→vector 後仍是 open=false、native=true，位置保留；console error 空。
- 又測 native 關閉／開啟，之後清除臨時測試座標並回到臺灣 2D，保留兩圖層勾選與站台供使用者操作。測試位置不是基地位置，未持久化。
